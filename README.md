# Sunidhi Chouhan — Portfolio

A personal portfolio showcasing my work, projects, engineering journey, and curiosity for building meaningful digital experiences.

Designed as an interactive journey rather than a conventional portfolio, the website combines thoughtful interface design, atmospheric visuals, motion, and storytelling to reflect how I approach software engineering.

## ✨ About

I'm a Software Engineer with 3.5+ years of experience building web applications and exploring how technology can solve meaningful problems.

I enjoy exploring how things work, solving problems that matter, and turning ideas into products people can actually use.

This portfolio brings together my work, experiments, reflections, and interests in frontend engineering, product development, Agentic AI, LLMs, and automation.

## 🚀 Features

- Interactive, scroll-driven portfolio experience
- Atmospheric visual design with animated canvas elements
- Responsive layouts across desktop, tablet, and mobile
- Reduced-motion support
- Accessible keyboard navigation and focus management
- Interactive project showcases
- Resume integration
- Performance-optimized assets and lazy-loaded project images
- Social sharing metadata and SEO configuration
